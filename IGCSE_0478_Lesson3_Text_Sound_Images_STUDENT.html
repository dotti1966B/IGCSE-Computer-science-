🔤 Part 1 — Representing text

A computer can only store binary, so every character you type — letters, digits, punctuation, spaces, even emoji — must be given a unique binary code. The complete list of characters a computer can use, with the code for each one, is called a character set.

Key definition
Character set: a defined list of characters recognised by a computer, where each character is given a unique binary code. Both the sending and receiving device must use the same character set, otherwise text is displayed incorrectly.

ASCII

ASCII (American Standard Code for Information Interchange) uses 7 bits per character, giving 27 = 128 different characters: upper- and lower-case English letters, digits 0–9, punctuation and some control codes (e.g. Enter). Extended ASCII uses 8 bits, giving 256 characters, adding symbols such as £ and accented letters.

The codes are in sequence, which is very useful: if you know A = 65, then B = 66, C = 67 and so on. Lower case starts at a = 97 (exactly 32 more than upper case), and the digit character 0 = 48.

Unicode

ASCII only covers English. Unicode was created so that computers worldwide could represent every writing system — Arabic, Chinese, Hindi, Greek — plus mathematical symbols and emoji. To do this, Unicode uses more bits per character (up to 32 bits, i.e. 4 bytes), so it can represent over a million different characters. The first 128 Unicode codes are the same as ASCII.

ASCIIUnicode
Bits per character7 (8 for extended)up to 32 (more bits per character)

Worked example
Encode the word Hi in 8-bit ASCII.
H = 72 = 01001000
i = 105 = 01101001
So Hi is stored as 01001000 01101001 — 2 characters × 8 bits = 16 bits.

🖼️ Part 2 — Representing images

A bitmap image is made up of a grid of tiny squares called pixels (picture elements). The colour of each pixel is stored as a binary number. The simplest image uses 1 bit per pixel: 0 = white and 1 = black.

🔍 Try it: a 1-bit image

Click the pixels to switch them on and off. Each row of 8 pixels is exactly one byte — watch the binary (and the hexadecimal from Lesson 1!) change.

00111100 = 3C
01000010 = 42
10100101 = A5
10000001 = 81
10100101 = A5
10011001 = 99
01000010 = 42
00111100 = 3C

8 × 8 pixels × 1 bit = 64 bits = 8 bytes

Colour depth

To show more than two colours, each pixel needs more bits. The number of bits used for each pixel is the colour depth. With n bits you can make 2n different colours.

Colour depthNumber of colours
1 bit21 = 2
2 bits22 = 4
4 bits24 = 16
8 bits28 = 256
24 bits (“true colour”)224 = 16,777,216

Resolution

The resolution of an image is the number of pixels it contains, given as width × height (e.g. 1920 × 1080). More pixels means each pixel represents a smaller part of the picture, so more detail can be shown.

Try it: resolution
Increase…Effect on image qualityEffect on file size
ResolutionMore detail; image stays sharp when enlarged (less “pixelated”)Larger — more pixels to store
Colour depthMore colours available, so colours are more accurate/realisticLarger — more bits for every pixel
Formula
Image file size (bits) = width × height × colour depth
Divide by 8 to get bytes. (Converting to KiB and MiB comes in Lesson 4.)
Worked example
An image is 640 × 480 pixels with a colour depth of 24 bits.
640 × 480 = 307,200 pixels
307,200 × 24 = 7,372,800 bits
7,372,800 ÷ 8 = 921,600 bytes
💬 Discuss
Two copies of the same photo are both 1920 × 1080. One has a colour depth of 24 bits; the other has 8 bits. Which looks better, which is the larger file — and why might someone choose the 8-bit version?

🔊 Part 3 — Representing sound

Sound is an analogue wave — it changes continuously. A computer cannot store a continuous wave, so the sound is sampled: at regular intervals, the amplitude (height) of the wave is measured and stored as a binary number. Played back, the samples rebuild an approximation of the original sound.

TermMeaning
SampleA measurement of the amplitude of the sound wave at one point in time
Sample rateThe number of samples taken per second, measured in hertz (Hz). CD quality is 44,100 Hz
Sample resolutionThe number of bits used to store each sample (also called bit depth). With n bits there are 2n possible amplitude values

🔍 Try it: sampling a sound wave

— original sound   ● samples   — what the computer stores
Increase…Effect on sound qualityEffect on file size
Sample rateMore samples per second, so the recording follows the original wave more closely — more accurateLarger — more samples to store
Sample resolutionMore possible amplitude values, so each sample is measured more precisely — more accurateLarger — more bits for every sample
Formula
Sound file size (bits) = sample rate × sample resolution × length in seconds
Divide by 8 to get bytes. (This is for one channel — a stereo recording is doubled.)
Worked example
A 10-second recording uses a sample rate of 44,100 Hz and a sample resolution of 16 bits.
44,100 × 16 × 10 = 7,056,000 bits
7,056,000 ÷ 8 = 882,000 bytes

Music streamed to your headphones usually sounds much better than a voice on a phone call. Using the words sample rate and sample resolution, suggest why.
