2

Overflow

An 8-bit register can only hold values from 0 to 255. If the true result of an addition is greater than 255, it doesn't fit — this is called overflow. The register keeps only the lowest 8 bits, silently producing the wrong answer unless the computer flags the error.

Worked example: 176 + 160

10110000 (176) + 10100000 (160) = 336 in true value — but 336 > 255, so this overflows an 8-bit register.

The register can only store the lowest 8 bits of the result, giving the incorrect value 01010000 (80) — nowhere close to the correct answer.

Fun fact

The famous 1980 arcade game Pac-Man has a “kill screen” at level 256 caused by exactly this kind of bug — the level counter is stored in a single 8-bit variable, which overflows when it tries to reach 256, corrupting half the screen!

3

Logical binary shifts

A logical shift slides every bit in a register left or right by a set number of places. A zero is shifted in at the empty end, and any bit pushed off the other end is lost.

  • A left shift (LSL) by n places multiplies the value by 2n — unless bits are lost off the left-hand (most significant) end.
  • A right shift (LSR) by n places divides the value by 2n, rounding down — bits lost off the right-hand (least significant) end are simply discarded.

Worked examples

00010110 (22) LSL 2 → 01011000 (88) — clean ×4, no bits lost.

11000011 (195) LSL 1 → 10000110 (134) — the leading 1 is lost off the end, so this is not simply 195×2 (390); the register can only show what's left.

10110100 (180) LSR 2 → 00101101 (45) — clean ÷4.

Two's complement — representing negative numbers

So far every number has been positive. But computers regularly need negative values too — a temperature below zero, an overdrawn bank balance, a game score going down. Two's complement is the standard way to represent negative binary integers.

In an 8-bit two's complement number, the most significant bit (MSB) tells you the sign: 0 means positive, 1 means negative. This gives a range of −128 to +127.

Finding the two's complement of a negative number

To represent −90: start from +90 in binary, invert every bit, then add 1.

+90  =  01011010

invert  =  10100101

+1     =  10100110  ← this is −90

Reading a two's complement number back to denary

Give the MSB place value −128 instead of +128, then add up as normal.

11110011: −128 + 64 + 32 + 16 + 2 + 1 = −13
