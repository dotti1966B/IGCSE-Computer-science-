Lesson 1: Denary, Binary & Hexadecimal

Why computers only understand binary — and how we convert between denary, binary and hexadecimal.

By the end of this lesson you will be able to:

  • Explain why computers represent all data using binary
  • Describe the denary, binary and hexadecimal number systems
  • Convert between positive denary, binary and hexadecimal numbers
  • Explain why hexadecimal is a useful way to represent data

Cambridge IGCSE 0478 syllabus reference: 1.1.1, 1.1.2, 1.1.3

1

Why do computers use binary?

Inside a computer, every value is stored using tiny electronic switches (transistors) that can only be in one of two states: on or off. We represent “on” as 1 and “off” as 0. Because there are only two possible digits, this is called a binary (base 2) system.

Every type of data — numbers, text, sound, images, instructions — is converted into binary before a computer can process it with logic gates or store it in registers. There is no way around this: it is a direct consequence of how the hardware works.

Discuss with your teacher: why can’t a computer just use denary (base 10) numbers directly, the way we do?

Three number systems

A number system's base (or radix) tells you how many different digits it uses. In each system, a digit's value depends on its place value — a power of the base.

Converting denary ↔ binary

Worked example: convert 90 to 8-bit binary

Start with the largest place value (128) and work down, asking “does this fit?”

1286432168421
01011010

90 = 64 + 16 + 8 + 2, so 90 in 8-bit binary is 01011010

Prefer division? See the divide-by-2 method

Divide by 2 repeatedly, noting the remainder each time, then read the remainders from bottom to top:
90÷2=45 r0 · 45÷2=22 r1 · 22÷2=11 r0 · 11÷2=5 r1 · 5÷2=2 r1 · 2÷2=1 r0 · 1÷2=0 r1
Reading bottom-to-top: 1011010 → padded to 8 bits: 01011010

Converting to & from hexadecimal

Every hexadecimal digit represents exactly 4 bits (a “nibble”). This makes converting between binary and hex very quick: split the binary number into groups of 4, then convert each group separately.

BinHexBinHexBinHexBinHex
00000 01004 10008 1100C
00011 01015 10019 1101D
00102 01106 1010A 1110E
00113 01117 1011B 1111F

Worked examples

Binary → hex: 1011 0110 → B 6 → B6

Denary → hex (via binary): 202 → 1100 1010 → C A → CA

Hex → denary: 3E → 0011 1110 → 62

Extension — going beyond 8 bits

The syllabus allows binary numbers up to 16 bits. The same method just works with more place values. For example, 51966 in denary is 1100101011111110 in 16-bit binary — which converts to hex as CAFE. Programmers sometimes deliberately choose “word” hex values like this as recognisable markers in memory!

6

Why use hexadecimal at all?

A computer still stores everything in binary — hexadecimal exists purely for the benefit of humans:

  • It is much shorter than binary — two hex digits instead of eight binary digits — so it's faster to read, write and spot mistakes in.
  • It converts to binary in a single, predictable step (unlike denary), because 16 is a power of 2.

You'll meet hexadecimal in several places on this course, including:

  • Colour codes in web design, e.g. #7A1F2E
  • MAC addresses, e.g. 00:1A:2B:3C:4D:5E
  • Memory addresses and error codes
