💬 Discussion prompts — what to look for

PromptModel answer
1. Why does a message containing an emoji take more storage?Emoji are not in ASCII, so the message must use Unicode, which uses more bits per character (an emoji typically needs up to 32 bits / 4 bytes, compared with 8 bits for an ASCII letter). More bits per character → larger file.
2. Same photo, 24-bit vs 8-bit colour depth24-bit looks better: 16,777,216 colours vs 256, so colours and gradients (e.g. skies, skin tones) are more realistic; 8-bit can show “banding”. 24-bit file is 3× larger (same pixels, 3× the bits per pixel). Someone might choose 8-bit to save storage or to load/transmit faster (e.g. a simple web graphic or icon).
3. Music vs phone call qualityPhone calls use a low sample rate (typically about 8,000 Hz) and lower sample resolution (around 8 bits), so the recorded wave is a rougher approximation and high frequencies are lost. Music streaming uses a much higher sample rate (e.g. 44,100 Hz) and resolution (16 bits+), giving a more accurate reproduction. Phone calls do this to reduce the amount of data sent in real time.

⚠️ Common misconceptions

  • Mixing up sample rate and sample resolution. Rate = how often (samples per second, Hz); resolution = how precisely (bits per sample). Use the sampler: rate moves dots left–right, resolution adds horizontal levels.
  • Confusing colour depth with number of colours. Colour depth is the number of bits; the number of colours is 2 to that power. Students often write “colour depth = 256”.
  • Thinking resolution is the physical size of an image. In 0478 it is the number of pixels (width × height).
  • Forgetting to divide by 8 when a question asks for bytes — and dividing by 1000 instead of 1024 later (flag this now; Lesson 4 picks it up).
  • Minimum bits for n colours. For 60 colours some students answer 5 (25 = 32 is too few) or round 60 → 64 and answer 64. Answer is the power: 6.
  • Believing “Unicode is always 16 bits”. Accept “more bits per character” — that is the syllabus wording. Unicode can use up to 32 bits per character.
  • The character ‘5’ is stored as 5. No — the character ‘5’ has ASCII code 53 (00110101). Character codes and number values are different things.
  • Higher quality has no cost. Every “increase” in resolution, colour depth, sample rate or sample resolution increases file size — exam answers need both halves (quality and file size).

Exam-style practice — mark scheme

Q1 [4] — one mark per point, max 2 for resolution and max 2 for colour depth:

  • Increasing resolution means more pixels (in the same image)…
  • …so more detail / image is sharper / less pixelated when enlarged, and file size increases
  • Increasing colour depth means more bits per pixel…
  • …so more colours can be represented / colours more accurate/realistic, and file size increases

Q2 [4] — any four:

  • Sound is analogue / a continuous wave
  • The amplitude of the wave is measured / sampled…
  • …at regular (set) time intervals
  • Each sample is stored as a binary value
  • Sample rate is the number of samples taken per second
  • Sample resolution is the number of bits used to store each sample
  • Higher sample rate / resolution gives a more accurate recording but a larger file

Q3 [1] — so that each character can be identified / distinguished from every other character (when the binary is converted back to text).

🚀 Extension ideas

  • Ask early finishers to encode their first name in 8-bit ASCII and swap with a partner to decode.
  • Explain why upper- and lower-case letters differ by exactly 32 — what single bit changes? (Bit 5, value 32: A = 01000001, a = 01100001.)
  • Calculate the size of a 3-minute stereo song at CD quality (44,100 Hz, 16-bit, 2 channels): 44,100 × 16 × 180 × 2 = 254,016,000 bits = 31,752,000 bytes. Keep the answer for Lesson 4 to convert to MiB.
  • Investigate: a 24-bit colour is often written as six hex digits (e.g. #7B1E3A). How many bits does each pair represent, and what do the three pairs stand for? (8 bits each — red, green, blue.)
  • Using the sampler, set the sample rate to maximum but the resolution to 1 bit, then the reverse. Which recording is closer to the original, and why does a good recording need both to be reasonably high?
